# ReAU
This is the PyTorch implementation for the paper:
> Yu Zhang, Yi Zhang, Yiwen Zhang ["ReAU: A Global-to-Local Perspective for Refining Alignment and Uniformity in Collaborative Filtering"](https://dl.acm.org/doi/10.1145/3770855.3817818). In Proceedings of the 32nd ACM SIGKDD Conference on Knowledge Discovery and Data Mining (SIGKDD’26).
## Environment Setting
```python
python == 3.8.18
```
